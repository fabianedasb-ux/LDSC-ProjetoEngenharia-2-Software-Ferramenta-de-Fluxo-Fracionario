\doxysubsection{Detailed Description}
Gerenciador de relatórios técnicos e exportação PDF. 

Esta classe é responsável por agregar os dados estáticos, os diagnósticos adimensionais, os resultados numéricos do choque de Welge e os gráficos gerados pela interface. O motor interno utiliza a sintaxe HTML5 e CSS3 inline para construir o layout do documento. Posteriormente, o relatório é renderizado vetorizado em formato PDF através das classes nativas QText\+Document e QPdf\+Writer do Qt.
