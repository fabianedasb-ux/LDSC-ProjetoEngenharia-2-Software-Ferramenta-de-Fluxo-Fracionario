\doxysubsection{Detailed Description}
Describes a data set by holding multiple \doxylink{class_q_c_p_data_range}{QCPData\+Range} instances. 

\doxylink{class_q_c_p_data_selection}{QCPData\+Selection} manages multiple instances of \doxylink{class_q_c_p_data_range}{QCPData\+Range} in order to represent any (possibly disjoint) set of data selection.

The data selection can be modified with addition and subtraction operators which take \doxylink{class_q_c_p_data_selection}{QCPData\+Selection} and \doxylink{class_q_c_p_data_range}{QCPData\+Range} instances, as well as methods such as \doxylink{class_q_c_p_data_selection_a46740c5aa7b80ae9b2abf6985d61b74f}{add\+Data\+Range} and \doxylink{class_q_c_p_data_selection_a385dd665e6690d39afb8bbd727b1e00b}{clear}. Read access is provided by \doxylink{class_q_c_p_data_selection_a6956acf6a9a49a353b4f9b58608978ad}{data\+Range}, \doxylink{class_q_c_p_data_selection_ac3b1c5e7713d380cd9e447f4556b94da}{data\+Ranges}, \doxylink{class_q_c_p_data_selection_abd8869ccb231ab991e8576de931f647d}{data\+Range\+Count}, etc.

The method \doxylink{class_q_c_p_data_selection_a4a2fbad1a6e4d1dd26fdfdf88956f2a4}{simplify} is used to join directly adjacent or even overlapping \doxylink{class_q_c_p_data_range}{QCPData\+Range} instances. \doxylink{class_q_c_p_data_selection}{QCPData\+Selection} automatically simplifies when using the addition/\+subtraction operators. The only case when \doxylink{class_q_c_p_data_selection_a4a2fbad1a6e4d1dd26fdfdf88956f2a4}{simplify} is left to the user, is when calling \doxylink{class_q_c_p_data_selection_a46740c5aa7b80ae9b2abf6985d61b74f}{add\+Data\+Range}, with the parameter {\itshape simplify} explicitly set to false. This is useful if many data ranges will be added to the selection successively and the overhead for simplifying after each iteration shall be avoided. In this case, you should make sure to call \doxylink{class_q_c_p_data_selection_a4a2fbad1a6e4d1dd26fdfdf88956f2a4}{simplify} after completing the operation.

Use \doxylink{class_q_c_p_data_selection_a17b84d852911531d229f4a76aa239a75}{enforce\+Type} to bring the data selection into a state complying with the constraints for selections defined in \doxylink{namespace_q_c_p_ac6cb9db26a564b27feda362a438db038}{QCP::\+\+Selection\+Type}.
