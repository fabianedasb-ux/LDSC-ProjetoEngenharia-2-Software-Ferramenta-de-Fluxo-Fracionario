\doxysubsection{Detailed Description}
Manages the position of an item. 

Every item has at least one public \doxylink{class_q_c_p_item_position}{QCPItem\+Position} member pointer which provides ways to position the item on the \doxylink{class_q_custom_plot}{QCustom\+Plot} surface. Some items have multiple positions, for example \doxylink{class_q_c_p_item_rect}{QCPItem\+Rect} has two:\+ {\itshape top\+Left} and {\itshape bottom\+Right}.

\doxylink{class_q_c_p_item_position}{QCPItem\+Position} has a type (\doxylink{class_q_c_p_item_position_aad9936c22bf43e3d358552f6e86dbdc8}{Position\+Type}) that can be set with \doxylink{class_q_c_p_item_position_aa476abf71ed8fa4c537457ebb1a754ad}{set\+Type}. This type defines how coordinates passed to \doxylink{class_q_c_p_item_position_aa988ba4e87ab684c9021017dcaba945f}{set\+Coords} are to be interpreted, e.\+g. as absolute pixel coordinates, as plot coordinates of certain axes (\doxylink{class_q_c_p_item_position_a2185f45c75ac8cb9be89daeaaad50e37}{QCPItem\+Position::\+set\+Axes}), as fractions of the axis rect (\doxylink{class_q_c_p_item_position_a0cd9b326fb324710169e92e8ca0041c2}{QCPItem\+Position::\+set\+Axis\+Rect}), etc. For more advanced plots it is also possible to assign different types per X/\+Y coordinate of the position (see \doxylink{class_q_c_p_item_position_a2113b2351d6d00457fb3559a4e20c3ea}{set\+TypeX}, \doxylink{class_q_c_p_item_position_ac2a454aa5a54c1615c50686601ec4510}{set\+TypeY}). This way an item could be positioned for example at a fixed pixel distance from the top in the Y direction, while following a plot coordinate in the X direction.

A \doxylink{class_q_c_p_item_position}{QCPItem\+Position} may have a parent \doxylink{class_q_c_p_item_anchor}{QCPItem\+Anchor}, see \doxylink{class_q_c_p_item_position_ac094d67a95d2dceafa0d50b9db3a7e51}{set\+Parent\+Anchor}. This way you can tie multiple items together. If the \doxylink{class_q_c_p_item_position}{QCPItem\+Position} has a parent, its coordinates (\doxylink{class_q_c_p_item_position_aa988ba4e87ab684c9021017dcaba945f}{set\+Coords}) are considered to be absolute pixels in the reference frame of the parent anchor, where (0, 0) means directly ontop of the parent anchor. For example, You could attach the {\itshape start} position of a \doxylink{class_q_c_p_item_line}{QCPItem\+Line} to the {\itshape bottom} anchor of a \doxylink{class_q_c_p_item_text}{QCPItem\+Text} to make the starting point of the line always be centered under the text label, no matter where the text is moved to. For more advanced plots, it is possible to assign different parent anchors per X/\+Y coordinate of the position, see \doxylink{class_q_c_p_item_position_add71461a973927c74e42179480916d9c}{set\+Parent\+AnchorX}, \doxylink{class_q_c_p_item_position_add5ec1db9d19cec58a3b5c9e0a0c3f9d}{set\+Parent\+AnchorY}. This way an item could follow another item in the X direction but stay at a fixed position in the Y direction. Or even follow item A in X, and item B in Y.

Note that every \doxylink{class_q_c_p_item_position}{QCPItem\+Position} inherits from \doxylink{class_q_c_p_item_anchor}{QCPItem\+Anchor} and thus can itself be used as parent anchor for other positions.

To set the apparent pixel position on the \doxylink{class_q_custom_plot}{QCustom\+Plot} surface directly, use \doxylink{class_q_c_p_item_position_a8d4f858f2089973967cf9cb81970ef0a}{set\+Pixel\+Position}. This works no matter what type this \doxylink{class_q_c_p_item_position}{QCPItem\+Position} is or what parent-\/child situation it is in, as \doxylink{class_q_c_p_item_position_a8d4f858f2089973967cf9cb81970ef0a}{set\+Pixel\+Position} transforms the coordinates appropriately, to make the position appear at the specified pixel values.

Sets the type of the position. The type defines how the coordinates passed to \doxylink{class_q_c_p_item_position_aa988ba4e87ab684c9021017dcaba945f}{set\+Coords} should be handled and how the \doxylink{class_q_c_p_item_position}{QCPItem\+Position} should behave in the plot.

The possible values for {\itshape type} can be separated in two main categories:\+

\begin{DoxyItemize}
\item The position is regarded as a point in plot coordinates. This corresponds to \doxylink{class_q_c_p_item_position_aad9936c22bf43e3d358552f6e86dbdc8ad5ffb8dc99ad73263f7010c77342294c}{pt\+Plot\+Coords} and requires two axes that define the plot coordinate system. They can be specified with \doxylink{class_q_c_p_item_position_a2185f45c75ac8cb9be89daeaaad50e37}{set\+Axes}. By default, the \doxylink{class_q_custom_plot}{QCustom\+Plot}\textquotesingle{}s x-\/ and y\+Axis are used.\end{DoxyItemize}
\begin{DoxyItemize}
\item The position is fixed on the \doxylink{class_q_custom_plot}{QCustom\+Plot} surface, i.\+e. independent of axis ranges. This corresponds to all other types, i.\+e. \doxylink{class_q_c_p_item_position_aad9936c22bf43e3d358552f6e86dbdc8a564f5e53e550ead1ec5fc7fc7d0b73e0}{pt\+Absolute}, \doxylink{class_q_c_p_item_position_aad9936c22bf43e3d358552f6e86dbdc8ac7d6aa89ceacb39658b0d6da061c789a}{pt\+Viewport\+Ratio} and \doxylink{class_q_c_p_item_position_aad9936c22bf43e3d358552f6e86dbdc8a01080fd00eaf09fa238ef6b73bbfef75}{pt\+Axis\+Rect\+Ratio}. They differ only in the way the absolute position is described, see the documentation of \doxylink{class_q_c_p_item_position_aad9936c22bf43e3d358552f6e86dbdc8}{Position\+Type} for details. For \doxylink{class_q_c_p_item_position_aad9936c22bf43e3d358552f6e86dbdc8a01080fd00eaf09fa238ef6b73bbfef75}{pt\+Axis\+Rect\+Ratio}, note that you can specify the axis rect with \doxylink{class_q_c_p_item_position_a0cd9b326fb324710169e92e8ca0041c2}{set\+Axis\+Rect}. By default this is set to the main axis rect.\end{DoxyItemize}
Note that the position type \doxylink{class_q_c_p_item_position_aad9936c22bf43e3d358552f6e86dbdc8ad5ffb8dc99ad73263f7010c77342294c}{pt\+Plot\+Coords} is only available (and sensible) when the position has no parent anchor (\doxylink{class_q_c_p_item_position_ac094d67a95d2dceafa0d50b9db3a7e51}{set\+Parent\+Anchor}).

If the type is changed, the apparent pixel position on the plot is preserved. This means the coordinates as retrieved with \doxylink{class_q_c_p_item_position_aa4ecf5b04c67049c05d37619e090820b}{coords()} and set with \doxylink{class_q_c_p_item_position_aa988ba4e87ab684c9021017dcaba945f}{set\+Coords} may change in the process.

This method sets the type for both X and Y directions. It is also possible to set different types for X and Y, see \doxylink{class_q_c_p_item_position_a2113b2351d6d00457fb3559a4e20c3ea}{set\+TypeX}, \doxylink{class_q_c_p_item_position_ac2a454aa5a54c1615c50686601ec4510}{set\+TypeY}.
