\doxysubsection{Detailed Description}
Representa o domínio discretizado do reservatório (o conjunto de pontos). 

Na abordagem analítica, a malha armazena o "{}perfil instantâneo"{} da simulação. Ela contém um vetor de células, onde cada célula representa um estado (Posição, Saturação) calculado para o tempo atual de injeção da água.
