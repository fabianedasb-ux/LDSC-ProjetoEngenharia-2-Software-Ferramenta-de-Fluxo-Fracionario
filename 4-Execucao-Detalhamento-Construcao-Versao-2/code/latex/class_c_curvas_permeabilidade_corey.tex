\doxysubsection{Detailed Description}
Implementação do modelo analítico de permeabilidade relativa de Corey. 

O modelo de Corey é uma correlação empírica clássica do tipo potência, amplamente utilizada na engenharia de reservatórios para sistemas bifásicos. Ele assume que as permeabilidades relativas são proporcionais a uma potência da saturação normalizada de água (\$\+S\+\_\+\{wn\}\$).

As equações fundamentais são dadas por:\+
\begin{DoxyItemize}
\item $ k_{rw} = k_{rw,max} \cdot (S_{wn})^{n_w} $
\item $ k_{ro} = k_{ro,max} \cdot (1 - S_{wn})^{n_o} $
\end{DoxyItemize}

Sendo a saturação normalizada:\+ $ S_{wn} = \frac{S_w - S_{wir}}{1 - S_{wir} - S_{or}} $
