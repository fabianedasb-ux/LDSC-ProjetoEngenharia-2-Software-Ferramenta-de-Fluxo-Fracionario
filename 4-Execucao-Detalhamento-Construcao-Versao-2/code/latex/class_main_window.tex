\doxysubsection{Detailed Description}
Camada de Apresentação (View) do simulador analítico. 

Esta classe herda de QMain\+Window e é responsável por toda a interação direta com o usuário. Ela coleta os parâmetros petrofísicos e de fluidos, repassa-\/os ao Controlador (\doxylink{class_c_simulador}{CSimulador}), e gerencia a atualização visual dos painéis de gráficos (\doxylink{class_q_custom_plot}{QCustom\+Plot}) e dos relatórios.

Além disso, a classe implementa um gerenciador dinâmico de folhas de estilo (QSS) para alternância em tempo de execução entre os temas Claro e Escuro, garantindo conforto visual ergonômico.
