\doxysubsection{Detailed Description}
Manages a legend inside a \doxylink{class_q_custom_plot}{QCustom\+Plot}. 

A legend is a small box somewhere in the plot which lists plottables with their name and icon.

A legend is populated with legend items by calling \doxylink{class_q_c_p_abstract_plottable_aa64e93cb5b606d8110d2cc0a349bb30f}{QCPAbstract\+Plottable::\+add\+To\+Legend} on the plottable, for which a legend item shall be created. In the case of the main legend (\doxylink{class_q_custom_plot_a73da53368aa4c2db3d874cf0db50d140}{QCustom\+Plot::\+legend}), simply adding plottables to the plot while \doxylink{class_q_custom_plot_ad8858410c2db47b7104040a3aa61c3fc}{QCustom\+Plot::\+set\+Auto\+Add\+Plottable\+To\+Legend} is set to true (the default) creates corresponding legend items. The legend item associated with a certain plottable can be removed with \doxylink{class_q_c_p_abstract_plottable_a3cc235007e2343a65ad4f463767e0e20}{QCPAbstract\+Plottable::\+remove\+From\+Legend}. However, \doxylink{class_q_c_p_legend}{QCPLegend} also offers an interface to add and manipulate legend items directly:\+ \doxylink{class_q_c_p_legend_acfe9694c45104a3359d3806ed366fcf7}{item}, \doxylink{class_q_c_p_legend_a91e790002d8bf15a20628a8e8841e397}{item\+With\+Plottable}, \doxylink{class_q_c_p_legend_a57ab86ab8b2a3762d4c1455eb5452c88}{item\+Count}, \doxylink{class_q_c_p_legend_a3ab274de52d2951faea45a6d975e6b3f}{add\+Item}, \doxylink{class_q_c_p_legend_ac91595c3eaa746fe6321d2eb952c63bb}{remove\+Item}, etc.

Since \doxylink{class_q_c_p_legend}{QCPLegend} derives from \doxylink{class_q_c_p_layout_grid}{QCPLayout\+Grid}, it can be placed in any position a \doxylink{class_q_c_p_layout_element}{QCPLayout\+Element} may be positioned. The legend items are themselves \doxylink{class_q_c_p_layout_element}{QCPLayout\+Elements} which are placed in the grid layout of the legend. \doxylink{class_q_c_p_legend}{QCPLegend} only adds an interface specialized for handling child elements of type \doxylink{class_q_c_p_abstract_legend_item}{QCPAbstract\+Legend\+Item}, as mentioned above. In principle, any other layout elements may also be added to a legend via the normal \doxylink{class_q_c_p_layout_grid}{QCPLayout\+Grid} interface. See the special page about \doxylink{}{The Layout System} for examples on how to add other elements to the legend and move it outside the axis rect.

Use the methods \doxylink{class_q_c_p_layout_grid_affc2f3cfd22f28698c5b29b960d2a391}{set\+Fill\+Order} and \doxylink{class_q_c_p_layout_grid_ab36af18d77e4428386d02970382ee598}{set\+Wrap} inherited from \doxylink{class_q_c_p_layout_grid}{QCPLayout\+Grid} to control in which order (column first or row first) the legend is filled up when calling \doxylink{class_q_c_p_legend_a3ab274de52d2951faea45a6d975e6b3f}{add\+Item}, and at which column or row wrapping occurs. The default fill order for legends is \doxylink{class_q_c_p_layout_grid_a7d49ee08773de6b2fd246edfed353ccaa0202730954e26c474cc820164aedce3e}{fo\+Rows\+First}.

By default, every \doxylink{class_q_custom_plot}{QCustom\+Plot} has one legend (\doxylink{class_q_custom_plot_a73da53368aa4c2db3d874cf0db50d140}{QCustom\+Plot::\+legend}) which is placed in the inset layout of the main axis rect (\doxylink{class_q_c_p_axis_rect_a949f803466619924c7018df4b511ae10}{QCPAxis\+Rect::\+inset\+Layout}). To move the legend to another position inside the axis rect, use the methods of the \doxylink{class_q_c_p_layout_inset}{QCPLayout\+Inset}. To move the legend outside of the axis rect, place it anywhere else with the QCPLayout/\+ \doxylink{class_q_c_p_layout_element}{QCPLayout\+Element} interface.
