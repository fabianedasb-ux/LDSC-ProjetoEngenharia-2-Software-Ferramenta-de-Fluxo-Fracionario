\doxysubsection{Detailed Description}
Representa um ponto discreto (volume elementar) no domínio do reservatório. 

Na abordagem analítica, a célula funciona como um container de dados que armazena o estado de uma saturação específica (Sw) e sua posição (x) correspondente em um determinado tempo (t).
