\doxysubsection{Detailed Description}
A layout that arranges child elements in a grid. 

Elements are laid out in a grid with configurable stretch factors (\doxylink{class_q_c_p_layout_grid_ae38f31a71687b9d7ee3104852528fb50}{set\+Column\+Stretch\+Factor}, \doxylink{class_q_c_p_layout_grid_a7b0273de5369bd93d942edbaf5b166ec}{set\+Row\+Stretch\+Factor}) and spacing (\doxylink{class_q_c_p_layout_grid_a3a49272aba32bb0fddc3bb2a45a3dba0}{set\+Column\+Spacing}, \doxylink{class_q_c_p_layout_grid_aaef2cd2d456197ee06a208793678e436}{set\+Row\+Spacing}).

Elements can be added to cells via \doxylink{class_q_c_p_layout_grid_adff1a2ca691ed83d2d24a4cd1fe17012}{add\+Element}. The grid is expanded if the specified row or column doesn\textquotesingle{}t exist yet. Whether a cell contains a valid layout element can be checked with \doxylink{class_q_c_p_layout_grid_ab0cf4f7edc9414a3bfaddac0f46dc0a0}{has\+Element}, that element can be retrieved with \doxylink{class_q_c_p_layout_grid_a602b426609b4411cf6a93c3ddf3a381a}{element}. If rows and columns that only have empty cells shall be removed, call \doxylink{class_q_c_p_layout_grid_a38621ca7aa633b6a9a88617df7f08672}{simplify}. Removal of elements is either done by just adding the element to a different layout or by using the \doxylink{class_q_c_p_layout}{QCPLayout} interface \doxylink{class_q_c_p_layout_grid_aee961c2eb6cf8a85dcbc5a7d7b6c1a00}{take} or \doxylink{class_q_c_p_layout_a6c58f537d8086f352576ab7c5b15d0bc}{remove}.

If you use \doxylink{class_q_c_p_layout_grid_a4c44025dd25acd27e053cadfd448ad7b}{add\+Element(\+QCPLayout\+Element\texorpdfstring{$\ast$}{*})} without explicit parameters for {\itshape row} and {\itshape column}, the grid layout will choose the position according to the current \doxylink{class_q_c_p_layout_grid_affc2f3cfd22f28698c5b29b960d2a391}{set\+Fill\+Order} and the wrapping (\doxylink{class_q_c_p_layout_grid_ab36af18d77e4428386d02970382ee598}{set\+Wrap}).

Row and column insertion can be performed with \doxylink{class_q_c_p_layout_grid_a48af3dd7c3a653d9c3d7dd99bd02e838}{insert\+Row} and \doxylink{class_q_c_p_layout_grid_a1e880a321dbe8b43b471ccd764433dc4}{insert\+Column}.

Sets the filling order and wrapping behaviour that is used when adding new elements with the method \doxylink{class_q_c_p_layout_grid_a4c44025dd25acd27e053cadfd448ad7b}{add\+Element(\+QCPLayout\+Element\texorpdfstring{$\ast$}{*})}.

The specified {\itshape order} defines whether rows or columns are filled first. Using \doxylink{class_q_c_p_layout_grid_ab36af18d77e4428386d02970382ee598}{set\+Wrap}, you can control at which row/\+column count wrapping into the next column/\+row will occur. If you set it to zero, no wrapping will ever occur. Changing the fill order also changes the meaning of the linear index used e.\+g. in \doxylink{class_q_c_p_layout_grid_a4288f174082555f6bd92021bdedb75dc}{element\+At} and \doxylink{class_q_c_p_layout_grid_a17dd220234d1bbf8835abcc666384d45}{take\+At}. The default fill order for \doxylink{class_q_c_p_layout_grid}{QCPLayout\+Grid} is \doxylink{class_q_c_p_layout_grid_a7d49ee08773de6b2fd246edfed353ccaac4cb4b796ec4822d5894b47b51627fb3}{fo\+Columns\+First}.

If you want to have all current elements arranged in the new order, set {\itshape rearrange} to true. The elements will be rearranged in a way that tries to preserve their linear index. However, empty cells are skipped during build-\/up of the new cell order, which shifts the succeeding element\textquotesingle{}s index. The rearranging is performed even if the specified {\itshape order} is already the current fill order. Thus this method can be used to re-\/wrap the current elements.

If {\itshape rearrange} is false, the current element arrangement is not changed, which means the linear indexes change (because the linear index is dependent on the fill order).

Note that the method \doxylink{class_q_c_p_layout_grid_adff1a2ca691ed83d2d24a4cd1fe17012}{add\+Element(int row, int column, QCPLayout\+Element \texorpdfstring{$\ast$}{*}element)} with explicitly stated row and column is not subject to wrapping and can place elements even beyond the specified wrapping point.
