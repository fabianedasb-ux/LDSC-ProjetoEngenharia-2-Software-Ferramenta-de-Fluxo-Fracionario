\doxysubsection{Detailed Description}
Controlador Principal do Sistema (Padrão Controller). 

Esta classe atua como a fachada unificada (Interface) entre a Camada de Apresentação (UI, \doxylink{class_main_window}{Main\+Window}) e o núcleo físico-\/matemático de Engenharia de Reservatórios.

A sua responsabilidade primária é orquestrar o ciclo de vida e garantir a sincronização termodinâmica antes de permitir a execução do Solver analítico.

Funcionalidades principais:\+
\begin{DoxyEnumerate}
\item Armazenar os parâmetros de entrada operacionais, PVT e de rocha.
\item Gerir rigidamente a memória alocada dos objetos em {\itshape heap} (Solver, Malha, Estratégia de Kr).
\item Validação preliminar do critério de Rapoport-\/\+Leas.
\end{DoxyEnumerate}
