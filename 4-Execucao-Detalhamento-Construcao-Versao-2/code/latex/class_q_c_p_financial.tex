\doxysubsection{Detailed Description}
A plottable representing a financial stock chart. 



This plottable represents time series data binned to certain intervals, mainly used for stock charts. The two common representations OHLC (Open-\/\+High-\/\+Low-\/\+Close) bars and Candlesticks can be set via \doxylink{class_q_c_p_financial_a5a59175d36279d71596e64d7bb65596f}{set\+Chart\+Style}.

The data is passed via \doxylink{class_q_c_p_financial_a72089e75b8a50d18097526c3c79fdb85}{set\+Data} as a set of open/\+high/\+low/\+close values at certain keys (typically times). This means the data must be already binned appropriately. If data is only available as a series of values (e.\+g. {\itshape price} against {\itshape time}), you can use the static convenience function \doxylink{class_q_c_p_financial_a9a058c035040d3939b8884f4aaccb1a7}{time\+Series\+To\+Ohlc} to generate binned OHLC-\/data which can then be passed to \doxylink{class_q_c_p_financial_a72089e75b8a50d18097526c3c79fdb85}{set\+Data}.
