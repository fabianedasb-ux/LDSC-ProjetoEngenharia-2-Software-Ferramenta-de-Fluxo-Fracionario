Detailed Description

Controlador Principal do Sistema (Padrão Controller).

Esta classe atua como a fachada unificada (Interface) entre a Camada de Apresentação (UI, MainWindow) e o núcleo físico-matemático de Engenharia de Reservatórios.

A sua responsabilidade primária é orquestrar o ciclo de vida e garantir a sincronização termodinâmica antes de permitir a execução do Solver analítico.

Funcionalidades principais:

  1. Armazenar os parâmetros de entrada operacionais, PVT e de rocha.
  2. Gerir rigidamente a memória alocada dos objetos em heap (Solver, Malha, Estratégia de Kr).
  3. Validação preliminar do critério de Rapoport-Leas.
