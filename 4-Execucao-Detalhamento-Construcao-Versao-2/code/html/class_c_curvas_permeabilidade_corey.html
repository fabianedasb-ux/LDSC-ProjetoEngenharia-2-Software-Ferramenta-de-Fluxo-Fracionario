Detailed Description

Implementação do modelo analítico de permeabilidade relativa de Corey.

O modelo de Corey é uma correlação empírica clássica do tipo potência, amplamente utilizada na engenharia de reservatórios para sistemas bifásicos. Ele assume que as permeabilidades relativas são proporcionais a uma potência da saturação normalizada de água ($S_{wn}$).
